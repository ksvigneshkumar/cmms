# UI Components Directory (`src/components/`)

This directory contains reusable React components used across the application.

## Folder Structure

- **`layout/`**: Contains structural components that form the shell of the application.
  - **`Sidebar.js`**: The side navigation menu (responsive drawer on mobile).
  - **`TopNav.js`**: The top navigation bar containing search, user profile, and notifications.
  - **`MobileMenuContext.js`**: React Context Provider for managing the open/close state of the mobile sidebar globally.
